# Kịch bản video demo

1. Giới thiệu mục tiêu Airbnb Backend API và các công nghệ.
2. Trình bày 5 model Prisma và quan hệ khóa ngoại.
3. Đăng ký user, đăng nhập, giải thích JWT Bearer và password hash.
4. Gọi route profile/ADMIN nếu giữ lại test routes; trình bày 401/403.
5. CRUD người dùng bằng ADMIN và chứng minh USER không thể sửa người khác hoặc đổi role.
6. CRUD vị trí, tìm kiếm và phân trang.
7. CRUD phòng, tìm theo `maViTri`, kiểm tra dữ liệu tiện ích.
8. Tạo booking, thử ngày sai/sức chứa vượt mức; chứng minh user không thể giả mạo chủ booking.
9. Tạo/sửa/xóa bình luận; chứng minh kiểm tra quyền sở hữu.
10. Upload avatar, ảnh phòng và ảnh vị trí bằng `formFile`.
11. Chạy test suite và xem checklist PASS/BLOCKED.
12. Gọi API production chỉ sau khi deployment được xác minh.
13. Kết luận, nêu giới hạn và phần cần hoàn thiện.
